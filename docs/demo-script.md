# 3-minute demonstration

1. Enter `Classroom 204 ka AC kaam nahi kar raha.` The decision card displays **ACT**, verified maintenance policy, permission and low risk; a ticket/audit event is created.
2. Enter `Lab 204 kal 2 se 4 baje tak book karna hai.` The card displays **ASK**. Select **Confirm booking** to demonstrate the separate controlled execution step.
3. Enter `I need a bonafide certificate.` The card displays **APPROVE** and a pending-approval status.
4. Enter `Book a lab without permission.` The Policy Guardian detects a conflict and the card displays **STOP**. Emphasize that no tool executed.

Close with: “Our innovation is not giving AI more autonomy — it is giving AI only the autonomy it is allowed to have.”
